# RoadLens — Nepal ANPR

A zero-license-cost, self-hosted Automatic Number Plate Recognition (ANPR) starter for authorized CCTV/RTSP feeds, webcams, images and videos.

## Goals
- Nepal-focused plate detection
- Live authorized CCTV/RTSP ingestion
- Multi-frame OCR consensus instead of trusting one frame
- Weather/lighting preprocessing
- Local SQLite event storage
- No paid cloud API required

> Accuracy is not guaranteed. Validate the system on your own cameras and conditions before operational use. Only process CCTV feeds you are authorized to access.
